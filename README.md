# 펫 태블릿

아이용 다마고치 웹앱. 안드로이드 태블릿 크롬에서 열어 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.

## 태블릿에 설치
1. 크롬으로 `https://s8848m.github.io/pet-tablet/` 열기
2. 오른쪽 위 ⋮ → **홈 화면에 추가** → 추가
3. 홈 화면 아이콘으로 열면 전체화면(가로)으로 실행됩니다. 처음 한 번 연 뒤엔 인터넷이 없어도 됩니다.

## 사용
- 왼쪽 버튼: 밥·놀기·씻기·재우기
- 오른쪽: 오늘의 할 일. 동그라미를 누르면 별 ⭐ 하나
- 펫 이름을 3초 길게 누르면 보호자 설정(비밀번호)

## 개발
외부 의존성 없음. `npm test` 로 규칙 테스트. `python -m http.server 8765` 로 로컬 확인.

## 보호자 메모

- **설정 화면**: 펫 이름을 3초 길게 누르기 → 4자리 비밀번호. 비밀번호를 잊으면 되찾을 수 없고 "처음부터 다시"만 가능합니다.
- **백업 파일**: `pet-backup-날짜.json`에는 비밀번호가 그대로 들어 있으니 아무 데나 올리지 마세요.
- **업데이트 반영**: `sw.js` 맨 위 VERSION 값을 올려야 합니다(v1 → v2 …). 반영되면 다음에 앱을 열 때 한 번 새로고침됩니다.
- **손상된 저장**: 저장 기록이 손상되면 원본이 브라우저 저장소의 `pet-tablet.broken` 키에 보관됩니다.
